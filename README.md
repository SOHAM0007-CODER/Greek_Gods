## ✨ Features

- **Immersive 3D Environments:** Procedurally generated god models built entirely with `three.js` geometries and custom shader materials.
- **Dynamic Camera Rig:** A smooth, damping-based Catmull-Rom camera track that follows your scroll wheel seamlessly down the layers of the pantheon.
- **Cinematic Post-Processing:** Real-time Bloom, Chromatic Aberration, Vignetting, and Film Grain powered by `@react-three/postprocessing`.
- **WebAudio Soundscape:** A custom generative audio engine that synthesizes unique ambient drones and chords for each deity on the fly, alongside speech synthesis for mythological lore.
- **GSAP Typography:** Fluid, staggering typography reveals and intricate HUD animations using the Greensock Animation Platform.

## 🛠️ Technology Stack

This project was originally prototyped in Vanilla HTML/JS and has been meticulously ported into a modern React ecosystem:

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **3D Rendering:** [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/) & [Three.js (r160+)](https://threejs.org/)
- **Animations:** [GSAP 3](https://gsap.com/)
- **State Management:** [Zustand](https://zustand-demo.pmnd.rs/)
- **Styling:** CSS Variables + Tailwind CSS integration

## 🏛️ The Pantheon

The descent takes you through five distinct layers of the cosmos:
1. **Zeus** (The Aether)
2. **Athena** (The Parthenon)
3. **Apollo** (The Heavens)
4. **Poseidon** (The Sea)
5. **Hades** (The Underworld)

## 🚀 Local Development

Want to run the experience locally?

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SOHAM0007-CODER/Greek_Gods.git
   cd Greek_Gods/olympos
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
